## 実行方法

### Processingで実行する場合

1. GitHubからリポジトリをダウンロードする
2. sketchフォルダをProcessingで開く
3. `ArtilleryInterception.pde` ファイルを開く
4. Processingの「実行」ボタンを押す


### 注意点

* 使用しているライブラリは、事前にインストールしてください。
* 画像・音声などの外部ファイルは、指定されたフォルダに配置してください。
